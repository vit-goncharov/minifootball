# Сайт минифутбола

Собирается командой из скилла:

    python3 ~/.claude/skills/minifootball/site.py

Посмотреть локально:

    python3 ~/.claude/skills/minifootball/site.py --serve

и открыть http://localhost:8765

## Что сюда попадает

Только готовый HTML и картинки. Исходные данные — `players.json`, `matches.json`,
`values.json`, `sheet.json` — остаются в `~/work/football` и в эту папку не копируются.

Не публикуется: рейтинг, история рейтинга, пометки `no_track`, `slow`, `handicap`,
подписи от других игроков, конфликтные пары. Стоимость в бананах публикуется.

Лица: только пиксельные портреты. Исключение — карточки тех, кому они уже вручены,
их скрины лежат в `assets/cards`.
