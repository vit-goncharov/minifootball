# Сайт минифутбола

Сайт собирается из папки проекта `football`, внутри которой лежит этот репозиторий:

    ./ff site       собрать локально
    ./ff preview    посмотреть на http://localhost:8765
    ./ff publish "сообщение"    собрать, закоммитить, запушить и дождаться GitHub Pages

## Что сюда попадает

Сюда попадают только готовый HTML и картинки. Исходные данные (`players.json`, `matches.json`,
`values.json`, `sheet.json`) остаются в `football/data` и в эту папку не копируются.

Не публикуются:
- рейтинг и его история;
- пометки `no_track`, `slow`, `handicap`;
- подписи от других игроков;
- конфликтные пары.

Стоимость в бананах публикуется. Сборка останавливается, если рядом с именем на странице
оказался рейтинг этого игрока.
